# 采集箱 · 需求说明

## 功能描述

采集箱是从妙手同步商品到本地的中转站。用户在妙手平台上架的商品会出现在采集箱，
用户选择后可以启动自动化处理，将商品移入成品仓库。

---

## 核心流程

```
妙手平台
  → 点"同步采集箱"拉取最新商品列表
  → 本地展示（分页表格）
  → 勾选商品 → 点"自动化处理"
  → 进入自动化流水线 → 商品移入成品仓库
```

---

## 验收标准

1. 同步后采集箱显示妙手当前在线商品，支持分页
2. 商品可按标题关键词搜索
3. 已入库（有自动化结果）的商品标注状态，不能重复添加到同一运行
4. 勾选并提交后进入自动化处理，不报"已开始"错误
5. 图片处理状态实时显示（后台 worker 轮询更新）

---

## 状态说明

| 状态 | 含义 |
|---|---|
| `pending` | 未处理 |
| `processing` | 正在处理（在某个运行中） |
| `done` | 已入库 |
| `failed` | 处理失败，可重试 |
