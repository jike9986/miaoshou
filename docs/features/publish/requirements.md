# 发布到店铺 · 需求说明

## 功能描述

把成品仓库里的商品发布到妙手店铺。支持单账号单店铺、多账号多店铺同时发布，也支持只认领进采集箱不上架。

---

## 核心流程

### 打开入口
仓库页勾选商品 → 点「发布」→ 弹出 `PublishDialog`。

### 账号与店铺选择
- **单账号用户**：一个「目标店铺」下拉框
- **多账号用户**：每个账号一张卡片，可勾选账号；账号下有多个店铺时，每个店铺一个复选框，可多选
- 打开弹窗时默认全选所有账号
- 未勾任何店铺时，该账号回落到第一个店铺
- 账号下无店铺时显示「暂无店铺（未绑定）」

### 其他表单项
- 定价模板：学员必填（`requiresTemplate = !allowClaimOnly`），老师可留空
- 汇率覆盖：留空则后端用缓存或实时汇率
- 「只认领进采集箱，不上架」开关
- 「接受语言不匹配」开关（仅站点不匹配时出现）

### 提交
- 发布不可撤销，必须 `confirm: true`
- 多账号时逐账号 × 逐店铺串行提交，每个组合一条发布记录
- 结果保留在弹窗结果区，可回看 repriced 明细与 warning

---

## 验收标准

1. 所有 `accounts.length > 1` 的用户（含 `member`）都能看到账号复选 + 每账号店铺多选
2. 单账号用户仍是原来的店铺下拉，行为不变
3. 连续勾选同一账号下的多个店铺，所有勾选都保留（不被覆盖）
4. 勾选 2 个以上账号时，每个「账号 × 店铺」组合都产生独立发布记录
5. 账号无店铺时明确提示，不静默失败
6. 按钮文案随勾选数量变化：「向 N 个账号发布 M 件」/「发布 M 件」
7. 一次最多 200 件（超限直接报错，不发请求）

## 已知偏差（详见 tasks.md）

- 只勾 1 个账号（多账号场景）会发到当前连接账号，不是勾选的那个 —— P0
- 前端仍按「站点语言不匹配」拦截，后端已不校验 —— P0
- 定时发布页的角色门控与店铺选择未与本功能对齐 —— P1
