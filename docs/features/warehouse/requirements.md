# 成品仓库 · 需求说明

## 功能描述

展示所有已入库的商品，支持分组管理、质检编辑、自动化结果预览与发布。

---

## 核心页面

### 仓库列表（/warehouse）
- 按分组筛选、关键词搜索
- 表格展示商品缩略图、标题、分类、SKU 数、状态
- 支持批量操作（批量修改分组、批量删除）

### 商品详情抽屉
- 基本信息：标题、分类、分组、重量/尺寸
- SKU 表格：展示所有规格组合的价格、库存
- 图片列表：可编辑顺序、删除、替换
- 自动化结果标签：展示妙手草稿写回内容

### 自动化结果页（/warehouse?tab=automation）
- 只显示 `draft_verified_revision == revision` 的商品
- 支持编辑图片/重量/尺寸，编辑后商品不消失
- 支持一键发布到妙手

---

## 验收标准

1. 编辑商品图片/重量/尺寸后，商品在自动化结果页依然可见
2. SKU 表格中颜色/尺码显示中文标签，不显示 hex ID
3. 商品列表支持按分组筛选，分组数据与采集箱共用
4. 鼠标滚动不触发页面缩放

---

## 状态说明

| 字段 | 含义 |
|---|---|
| `draft_verified_revision` | 等于 `revision` 时才在自动化结果页显示；编辑后必须同步更新 |
| `revision` | 每次写操作递增（由 `revision_guard` 控制） |
| `automation_result` | JSON，妙手草稿写回内容，存在时才有自动化结果 |
