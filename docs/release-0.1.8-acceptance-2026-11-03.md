# 0.1.8 发布恢复、桌面会话与交付验收

## 本轮行为

- 自动化正式提交前持久化运行、逐件结果、批次和发布台账的关联；响应丢失或重启后仍能核对。失败与未知结果保留显示，仅最终失败或取消允许重试发布，重试不重复标题和图片处理。
- 回执按账号、店铺、操作用户、任务关联和本次提交时间匹配；保存上游回执 ID，避免旧回执或同秒重试结果覆盖新任务。缺失时间或多人共用妙手 key 导致归属不明时保持待核对。兼容真实 `platformItemId`。
- 定时每轮使用独立批次；上游受理不显示为成功。最终回执更新所属历史，未知结果不自动重新发布。
- 批量认领复用采集箱已有载体，每批复制 100 份，再覆盖成品数据；保存后按实际提交的标题、价格、采购价和规格读回核验，读回异常阻断发布。
- 空采集箱缓存正在刷新时显示加载状态；有缓存继续显示商品，读取完成后才显示空结果。切换软件用户、妙手账号或离页后，旧异步结果不能覆盖当前状态。
- 桌面登录会话使用 Windows 系统加密保存；历史明文会话迁移后删除，加密不可用只保留内存。IPC 校验窗口、主 frame 和可信页面，外部顶层导航被阻断。退出持久清理失败会明确提示。
- 商品重量和尺寸不再因为数值合理或非空就显示已核验，核验依据必须关联当前 revision，未改写无法确认的实物数值。

两条业务流程继续保留：自动化处理采集箱原始商品后发布；成品仓库商品已经编辑，学员认领后改价发布。多人共用妙手账号时，其上游采集箱属于该妙手账号共同数据；软件用户的认领、任务、发布台账仍各自隔离。
