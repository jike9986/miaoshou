# Windows 桌面原生缩放与会话验收（2026-11-03）

## 范围与方法

- 仓库 `tk-desktop`，分支 `master`；先验收已安装客户端 0.1.7，再对 `release/win-unpacked` 0.1.8 目录包重复验收，下表记录 0.1.8 结果。
- 为每个缩放因子启动独立 Electron 进程和独立用户目录，不使用 CDP Emulation 或 `set_viewport_size`。
- 启动参数分别为 `--force-device-scale-factor=1 / 1.25 / 1.5`，主进程对隔离窗口调用 `BrowserWindow.setContentSize`，渲染进程读取实际尺寸与 `devicePixelRatio`。
- 这是 Electron 原生进程缩放验收；未修改 Windows 系统 DPI，不能据此声称已覆盖多显示器切换或安装器原生对话框的系统 DPI。
- 应用内页面使用 Playwright CDP 检查，并用 `Page.startScreencast` 截图。所有 `/api/v1/` 非只读请求均被验收拦截器接管：每个缩放进程自动保存工作流默认值两次，`POST /system/settings` 仅在测试进程内模拟 200 回执；其余写请求一律阻断，实际未出现。服务器没有因此发生写入。
- 用户主窗口 CDP 9335 全程只读，前后均为 1440×920，DPR 1.25。

没有页面 JavaScript 错误，没有已完成 API 响应的 HTTP 错误，没有发布、处理或认领写入。截图前等待采集箱读取结束，仓库使用服务器实际只读数据。

验收曾发现空缓存正在刷新时短暂显示“采集箱是空的”。已在 `ProductPicker.tsx` 修正：空列表读取时显示带状态标签的骨架；有缓存时继续显示商品卡片；只有读取完成后才显示空结果。独立渲染验证覆盖首次加载、空缓存刷新、保留已有卡片、确认空态和错误后重试五种状态，全部通过。前端类型检查和设计护栏通过；0.1.8 目录包已包含修正并通过上表复验。

## 会话加密交叉复审

主进程会话读写同时校验调用者 WebContents、主 frame 和可信页面 URL；生产只信任打包入口 `resources/web/index.html`，开发只信任固定本地开发页面。外部顶层导航和重定向被阻断。

对原子替换失败后可能恢复旧登录态的问题，已复审旧密文删除/空记录覆盖的降级处理；无法清除持久化会话时，退出操作返回失败并向用户提示。会话存储专用测试 5/5、前端迁移和内存降级测试 4/4 通过。

另在真实 Windows Electron `safeStorage` 下运行当前构建的 `sessionVault`，只使用隔离目录中的虚拟令牌，验证：系统加密可用、密文落盘且无明文、重启恢复、退出清除、再次重启仍未登录，所有布尔断言通过。没有读取或修改用户主目录中的会话。

对最终 0.1.8 目录包，再从实际 preload 桥接调用主进程 IPC，14 项布尔断言全部通过：可信入口读写、非法类型和超长值拒绝、原会话保留、密文无明文、外部导航阻断、不可信页面读写拒绝，以及重启恢复、正常退出返回成功、退出后再启动仍未登录。此过程使用独立数据目录与虚拟令牌，API 指向不可用的本地地址，未访问真实账号数据。验收发现并修复了同一同步 IPC 分支重复设置 `returnValue` 导致保存和退出回执始终为失败的问题；最终目录包已经包含修复并完成上述复验。
