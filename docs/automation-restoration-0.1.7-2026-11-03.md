# 0.1.7 自动化上品恢复与交付验收

## 问题与修复

恢复软件账号登录时，普通学员的自动化菜单、路由及处理接口被错误归入全局管理权限，导致“自动化上品”入口消失。0.1.7 增加独立自动化权限，学员可以处理当前绑定妙手账号的采集箱商品、选择共享定价模板和尺码图、发布本人处理结果。共享模板、尺码图管理及全局记录仍按老师/管理员权限控制。

自动化处理和成品仓库保持两条业务流程：自动化使用处理后的价格发布，不进入仓库认领载体或再次定价；个人处理结果不能覆盖共享成品或他人的处理结果。个人运行记录、图片任务和发布记录按软件用户隔离。多人绑定同一个妙手账号时，上游采集箱仍是该妙手账号的共同数据，详见 [此前交付记录](delivery-acceptance-2026-11-03.md)。

图片任务完成后重新保存妙手草稿并读回核对，核对通过才允许发布。后台图片失败、超时、旧版本任务、解绑及停止处理均阻止未经核对的正式发布。已提交但未取得最终回执的商品保留待核对状态，不能显示为发布成功。未处理、明确处理失败、图片未完成及停止后未提交的商品保留选择；发布失败或结果不确定时保留记录供核对。

## 验证结果

- 后端全量测试 585 项通过；相关修改文件 Ruff 通过。
- 前端 Node 测试 84 项通过；`pnpm check`、生产构建通过，保留 25 条既有 lint warning，0 error。
- 业务隔离与图片生命周期由不同智能体交叉复审通过。
- 隔离浏览器模拟上游 6 项通过：图片后台排队完成后续发、无需翻译图片、后台失败、等待时停止、处理请求返回前停止、续发准备请求返回前停止。失败和停止场景均未发送正式发布；刷新未重复发布，无未匹配接口、外网请求或 renderer 异常。
- 当前实际安装版学员会话通过：自动化导航与页面、采集箱、文字/图片开关、定价模板选用弹窗、Esc 关闭并恢复焦点、共享资产管理入口隐藏、定时发布入口、仓库 20 张卡片、设置显示 v0.1.7。没有 renderer 异常或 API 错误，结束停在自动化上品。
- CDP 模拟 1440×900、1180×720、900×700 视口均无横向溢出，开始处理按钮可见，截图已查看。当前账号采集箱为空，实际安装验收覆盖空状态；非空处理闭环由上述隔离浏览器与后端测试覆盖。

首次视口验收遗留了 1180×720 的模拟渲染尺寸，使用户的实际窗口右侧、底部出现留白。已保留原 profile 重启安装版，实际窗口与页面恢复为 1440×920 CSS 像素（125% 缩放对应 1800×1150 物理像素），无横向溢出，当前截图已检查。后续实际安装版验收脚本只读取原生视口，不再改变用户主窗口的模拟尺寸。

本轮没有实际处理或再次发布商品。此前罗蔓账号 C lm shop 的单件真实发布成功记录继续保留，见 [0.1.6 验收](delivery-acceptance-2026-11-03.md)。这些回归不等于全部商品、店铺和系统环境已完成真实发布验收。
