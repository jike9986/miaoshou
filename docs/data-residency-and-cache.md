# 数据驻留与本机缓存

本说明描述当前实现的数据去向。服务端是业务数据权威来源；桌面端列表缓存只负责加快首屏显示，在线刷新后以服务端响应为准。

## 服务端持久化

服务端数据库由 `AOHUANG_DATABASE_URL` 选择：生产部署使用已配置的 PostgreSQL；没有配置时，应用退回当前 `AOHUANG_DATA_DIR` 下的 SQLite 文件，适用于本机开发或单机部署。启动时会按所选数据库检查结构版本，PostgreSQL 不会在启动时自动改表。

数据库保存需要跨客户端、登录和重启继续存在的业务状态：

| 数据 | 持久化与访问边界 |
| --- | --- |
| 软件用户 | 用户名、展示名、邮箱及验证状态、角色、启用状态、密码哈希和当前登录 token 的摘要；密码使用带盐 scrypt，token 使用 SHA-256 摘要 |
| 邮件验证与限流 | 按邮箱和用途保存验证码 HMAC 摘要、有效期、错误次数和消费状态；保存登录/发信限流记录。数据库不保存验证码明文 |
| 妙手绑定 | 软件用户与妙手账号的绑定、绑定人和绑定时间；每个软件用户最多一个妙手账号，同一妙手账号允许多个软件用户绑定 |
| 妙手凭据和店铺 | AppSecret 加密保存，响应只提供脱敏提示。服务端使用独立且稳定的 `AOHUANG_CREDENTIAL_KEY`；AppKey 仍是普通数据库字段，未单独加密 |
| 商品 | 共享成品目录、商品字段和完整处理数据、规格核验信息；未入仓的自动化结果按任务归属和当前妙手绑定校验访问 |
| 个人业务状态 | 学员认领、发布回执、批次及逐件结果、自动化任务、定时任务和执行记录。发布记录按软件用户与目标妙手账号/店铺区分；同一成品可被多人分别认领 |
| 配置与审计 | 用户处理配置、价格规则、违规词、服务配置及操作审计；全局维护内容按老师/管理员权限开放，角色管理保留最高管理员限制 |

共享妙手账号表示这些用户访问的是同一个上游采集箱，看到相同的上游商品是预期行为；个人认领、任务和发布记录仍按软件用户隔离。老师的全局管理可见性属于角色授权，不能用客户端筛选代替服务端权限检查。

图片文件、图片处理结果和日志还可能保存在服务端配置的数据目录中；数据库内的图片 URL 不等于图片文件本身。备份范围应同时覆盖实际使用的文件目录或外部图床。生产凭据解密密钥应单独保管，不能只备份数据库而丢失密钥。

生产 PostgreSQL 的备份由服务器部署流程维护。备份恢复验证、数据库磁盘加密及备份介质加密属于运维控制，不由应用代码保证；部署环境应单独核实权限、保存周期和恢复演练。

## 桌面端本机存储

桌面端 `localStorage` 保存个人登录 token、用户 ID/展示名/角色、首次设密状态、可配置的服务端地址、部分偏好和列表摘要。登录和注册密码不写入列表缓存；妙手 AppSecret、SMTP 密码、数据库凭据及完整商品详情也不写入这一磁盘缓存。

个人 token 和列表摘要当前没有额外加密，也没有使用 Windows 凭据保险库。缓存隔离控制应用按身份读取哪个分桶，不阻止同一 Windows 用户或有应用配置目录访问权的程序读取本机存储。角色字段只是界面展示和缓存分桶信息，服务端仍以 token 对应的真实身份授权。共享电脑应使用各自的 Windows 用户配置文件，并在交接前退出及清除本人商品缓存。

### 列表缓存范围

- 仅持久化成功返回的采集箱和成品仓库列表，内容可能包含标题、商品 ID、价格、重量摘要、图片 URL、分页和统计信息；没有额外预取未打开的全部商品，也不是可独立使用的离线数据库。
- 分桶维度为软件用户稳定 ID、角色、规范化后的 API 服务地址、妙手账号 ID；页码、每页数量、店铺、状态、关键词等列表参数进入查询键。只有 token、没有稳定用户 ID 的旧身份不写磁盘缓存。
- 每个身份下的每个妙手账号最多保留最近 24 个列表结果，采集箱和仓库共用此额度；单桶 JSON 序列化上限为 1,000,000 个字符，实际占用字节取决于存储编码。超过容量时先淘汰较旧列表。
- 超过 7 天、格式损坏或已标记失效的条目不用于恢复；读取该身份缓存时会尝试移除过期/损坏内容。其他尚未登录身份的旧分桶不会被后台定时扫描清理。
- 列表摘要来自已获授权的服务端响应，不作为认领成功、正式发布成功或权限有效的证明。写操作仍请求服务端；网络错误时显示的旧列表不能证明妙手当前状态。

### 刷新与清理

进入采集箱或成品仓库时先恢复当前分桶的可用列表，再在线核对；窗口重新获得焦点时也会核对。采集箱前台每 30 秒轮询，后台停止轮询。采集箱的手动刷新会携带 `refresh=true`，要求服务端绕过短时上游缓存，避免本机重复显示旧结果。

采集箱对当前账号和列表查询首次成功在线核对前保持只读；占位列表、上游降级和查询失败时也禁用商品选择及执行入口。首次核对通过后的正常后台轮询不反复锁定列表，仍可正常选择和翻页。

服务端采集箱内存缓存默认 10 秒，可用 `AOHUANG_COLLECT_BOX_CACHE_TTL` 覆盖；按妙手账号记录、凭据 HMAC 指纹及查询参数区分，最多 256 个结果。它不落客户电脑，也不代替数据库；进程重启后丢失。上游故障时允许返回旧结果，并标记 `degraded` 和 `staleSeconds`；仓库标注每次按当前数据库重新计算。即使绕过本服务缓存，也无法保证妙手自身尚未同步的数据立即出现。

设置 → 关于与更新 → 本机缓存 → **清除商品缓存**，会清除当前软件用户、角色和服务地址对应的采集箱/仓库内存列表与磁盘分桶；下次打开页面重新加载。它保留个人登录 token、妙手绑定、服务器商品和其他软件用户的缓存。

退出登录会移除当前登录身份并清理内存查询，磁盘列表保留供本人下次登录恢复。因此“退出”和“清除商品缓存”是两个动作；若要移交共用电脑，先清商品缓存，再退出。该清理入口不承诺清除 Chromium 图片缓存或全部应用设置。
